# AI-SOC — AI-Enhanced Security Operations Center

An academic graduation project focused on developing an AI-enhanced Security Operations Center (SOC) that combines SIEM, security monitoring, threat detection, and AI-assisted incident analysis.

## Project Overview

AI-SOC aims to support SOC analysts by collecting and analyzing security events, identifying suspicious activities, generating alerts, and helping investigate potential security incidents.

## Key Areas

- Security Information and Event Management (SIEM)
- Security Event Monitoring
- Threat Detection and Incident Analysis
- Network Security
- AI-Assisted Security Analysis
- SOC Workflows

## Technology Stack

- Python
- FastAPI
- React
- Vite
- Linux / Kali Linux
- SIEM Concepts

## Project Status

Currently under development as part of a university graduation project.

## Disclaimer

This project is developed for educational and cybersecurity learning purposes.
